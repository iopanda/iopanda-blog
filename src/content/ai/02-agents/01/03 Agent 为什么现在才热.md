# Agent 为什么现在才热

> 上一章回答了「Agent 是什么」:以模型为大脑、能自主规划并行动的完整系统。可这里有个绕不开的矛盾——「智能体」一词 1980 年代就出现在 SOAR、BDI 这类经典系统里,强化学习更让 AlphaGo 在 2016 年震惊世界,为什么 Agent 直到 2023 年才人尽皆知、人人可搭?本章沿历史脉络讲清三件事:Agent 经历了哪三代形态、是哪三个催化剂把「实验室里的 Agent」变成「产品里的 Agent」、以及经典 Agent 与今天 LLM Agent 的本质差别到底在哪。

**学习目标**:学完本章,你将能够——

1. 说出 Agent 研究的三个时代(经典 Agent / RL Agent / LLM Agent)及各代代表作;
2. 解释三个催化剂——通用推理、function calling、上下文窗口——各自补上了 Agent 的哪块短板;
3. 用一张表讲清 LLM Agent 与经典 Agent 的本质差异(无需手写状态机、用自然语言规划);
4. 说清「为什么 2023 年后才爆发」:催化剂何时到货、需求如何被引爆;
5. 用「催化剂框架」判断:一个任务今天做 Agent,到底还缺不缺东西。

## 1. 概念:不是新词——三代 Agent 的历史脉络

「AI Agent」不是 2023 年的发明。要理解「为什么现在才热」,先看清它走过的三个时代——每一次「热」都是底层能力换代的信号:

| 时代 | 代表作 | 大脑怎么来 | 规划怎么做 | 为什么没普及 |
|---|---|---|---|---|
| 经典 Agent(1980s~) | SOAR(1987)、BDI(1995) | 专家手写符号规则 | 状态机/意图推理,逻辑严密 | 知识获取瓶颈:每条规则都靠人写,换个领域重写一套 |
| RL Agent(2010s) | DQN(2015)、AlphaGo(2016) | 与环境试错,学出策略 | 学到的隐式策略,专精单一环境 | 一任务一训练:要仿真环境、要设计奖励,换个游戏几乎从头再来 |
| LLM Agent(2022~) | ReAct、ChatGPT 生态、AutoGPT | 预训练语言模型 | 用自然语言想、拆、改 | 曾经缺的底座(推理/接口/记忆)在 2023 年前后凑齐,见第 3、4 节 |

- **经典 Agent**:1980 年代符号主义高峰。SOAR 用产生式规则模拟通用解题,BDI 用信念-愿望-意图(belief-desire-intention)建模理性行动。它们把「规划」研究得很透,但知识全靠人一条条写进规则,最终困在专家系统里——这就是经典的「知识获取瓶颈」。
- **RL Agent**:2010 年代深度强化学习。AlphaGo 不需要人教围棋规则,自己与自己对弈学出策略。但每个技能都要单独训练:换任务 = 换环境、换奖励、重新算——AlphaGo 不会下象棋。
- **LLM Agent**:2022 年底起,语言模型本身成了「通用大脑」:ReAct 论文(2022.10)证明让模型边想边做能显著提升任务成功率;ChatGPT(2022.11)让通用推理第一次触达大众;AutoGPT、BabyAGI(2023.03~04)示范了「模型自主拆任务、反复调工具」的成品长什么样。

一句话:**三代 Agent 的差别不在「Agent」这个词,而在「大脑从哪来」**——手写规则 → 单任务训练 → 通用预训练,每一代都在降低「造一个 Agent」的边际成本。

## 2. 为什么需要:理解「热」的因果,而不是追热点

学本章不是为八卦 AI 编年史,而是为了不被「2023 突然火了」的说法误导,建立三个判断力:

- **判断时机**:为什么 2018 年没人做出 AutoGPT?不是前人笨,是底座没到。理解催化剂,你才知道一个 Agent 想法今天能不能落地、会卡在哪一层(呼应 04 章:模型能力边界)。
- **避免两个极端**:一说 Agent 就以为是 2023 新发明——错,经典 Agent 的规划、意图建模思想今天仍被复用(02.03);一说有 LLM 就自动是 Agent——也错,催化剂缺一块,系统就退回「高级聊天框」(05 章会亲手验证)。
- **定位工程重点**:三个催化剂恰好对应你后面要学的三条线——模型能力(01)、工具协议(02.04)、上下文工程与记忆(02.02 / 02.05)。知道「热」在哪一层,就知道该补哪一层。

## 3. 作用与位置:三个催化剂是 Agent 的三块基座

把「Agent 为什么现在才热」翻译成工程语言:**让 Agent 成立的三块基座,在 2023 年前后同时到货了**。

| 催化剂                | 到货标志                                                                                           | 补上的短板                                       | 对应课程线                           |
| ------------------ | ---------------------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------- |
| ① 通用推理             | GPT-3 起 few-shot/CoT 能力涌现;ChatGPT(2022.11)让大众用上                                                | 模型能「想」:拆任务、自纠错,不必为每个任务手写规则或重训               | 01 模型能力                     |
| ② function calling | OpenAI API(2023.06.13)让模型输出结构化工具调用;各家跟进,MCP(2024.11)统一协议                                       | 模型能「做」:工具调用从「提示词 + 正则解析」的脆弱 hack 变成受训能力     | 02.04 Tool Use and Protocols |
| ③ 上下文窗口            | 约 2K(GPT-3,2020)→ 16K(2023.06)→ 128K(GPT-4 Turbo,2023.11)→ 200K/1M(Claude 3 / Gemini 1.5,2024) | 模型能「记」:装下 system 规则 + 多轮历史 + 工具结果,多步任务不「失忆」 | 02.02 上下文 / 02.05 记忆      |

- ①是**大脑**:没有通用推理,规划只能人写死——退回经典 Agent 的知识获取瓶颈;
- ②是**手**:没有可靠的工具调用协议,每接一个工具都要写一套脆弱解析代码,没法产品化;
- ③是**工作台**:窗口太小,Agent 做第二步就忘了第一步,运行循环(03 章)根本转不起来。

## 4. 详细介绍:为什么 2023 年后爆发

### 4.1 一条时间线看清爆发过程

```
可落地度
  ▲                     LLM Agent 时代
  │                              ★ 2023.11 GPT-4 Turbo:128K 上下文
  │                         ★ 2023.06 function calling + 16K 上下文
  │                    ★ 2023.03 GPT-4;AutoGPT/BabyAGI 引爆开源
  │               ★ 2022.11 ChatGPT:通用推理触达大众
  │          ★ 2016 AlphaGo:能赢棋,但只会下棋(RL Agent)
  │     ★ 1987 SOAR:专家系统,规则靠人写(经典 Agent)
  └──────────────────────────────────────────→ 时间
```

- **2022.10~11**:ReAct 论文证明「推理 + 行动」交织有效;ChatGPT 上线两个月破亿用户——通用推理从论文走进普通人的对话框。
- **2023.01~03(研究预热)**:Toolformer 让模型自监督学会用工具,HuggingGPT 把「LLM 当调度中枢」写成系统论文——产品还没火,研究已经铺好了路。
- **2023.03~04**:GPT-4 发布(上下文首次到 32K);AutoGPT、BabyAGI 开源,数周登顶 GitHub 趋势榜,「给模型一个目标,它自己干」第一次被大众看见;LangChain 生态同步起飞。
- **2023.06.13**:OpenAI 发布 function calling,同时推出 16K 上下文模型——模型能按 JSON schema 输出「要调用哪个函数、参数是什么」。这一天被很多开发者视为「Agent 基建日」:工具调用从 hack 变成官方受训能力。
- **2023.11**:GPT-4 Turbo 把上下文推到 128K;GPTs 与 Assistants API 让「定制 Agent」下沉到普通用户。
- **2024~**:Claude 3(200K)、Gemini 1.5(1M)继续放大窗口;Devin、Claude Computer Use 等产品让 Agent 替你操作电脑;MCP 统一工具接入;Agent 综述文献爆发(见引用)——学界正式把「LLM Agent」当成独立研究领域。

### 4.2 爆发公式:催化剂 × 触达 × 成本

- 三个催化剂解决**能不能做**(推理/工具/记忆);2023 年还有两个放大器决定**做给谁看、做不做得起**:
  - **触达**:ChatGPT 把「模型会推理」变成公共常识,需求端(产品、资本、开发者)被瞬间点燃;
  - **成本**:API 价格一年内下降一个数量级,token 从「实验室预算」变成「产品预算」——AutoGPT 这类要跑很多步的 Agent 才烧得起。
- 所以「2023 后爆发」的准确说法是:**不是 2023 年发明了 Agent,而是「通用推理 + 工具协议 + 大窗口」三块基座在这一年凑齐,又赶上大众触达与成本曲线下降**——需求、能力、价格三线交汇。

### 4.3 LLM Agent 与经典 Agent 的本质差异

| 对比维度 | 经典 Agent(SOAR/BDI) | LLM Agent |
|---|---|---|
| 规划方式 | 手写状态机 / 形式化意图推理 | 自然语言 Thought:想 → 做 → 看 → 再想(03 章 ReAct) |
| 知识来源 | 专家逐条编码,写不进去就不会 | 预训练语料里的世界知识,零样本/少样本即用 |
| 换领域成本 | 重写规则库(数月~数年) | 改一段 prompt、换几个工具(分钟~天) |
| 工具接入 | 深度定制,与推理逻辑耦合 | 声明式接入:给函数名 + JSON schema(②催化剂的产物) |
| 失败模式 | 规则之外就死板或报错,但可预期 | 流畅但可能幻觉、跑偏(04 章),不确定性与生俱来 |
| 一句话 | 精确的「机械执行者」 | 通用的「即兴行动者」 |

- 最本质的一条:**经典 Agent 的智能写在程序里(状态机),LLM Agent 的智能写在语言里(prompt + 模型权重)**。前者每改一步行为都要动代码,后者改一句话就行——这正是「无需手写状态机、用自然语言规划」带来的工程革命。
- 这张表也回头解释了 01 章的自主度光谱:经典 Agent 的高自主建立在「规则完备」上,LLM Agent 的高自主建立在「语言理解」上——前者怕没写到的规则,后者怕理解错(04 章展开)。

## 5. 动手活动:给课程助教做「催化剂体检」

> [!example] 动手活动:催化剂 × 课程助教对照表
>
> **目标**:输出 `agent-catalyst-02.md`——用三个催化剂给「课程助教 Agent」做一次可行性体检。
>
> **步骤**:
> 1. 选任务:「学员问外键——先查课程资料,再按学员进度出 5 道题,存成 md 发给学员」;
> 2. 逐催化剂填表:没有①通用推理,任务哪一步会卡?没有②function calling,「查资料/存文件」怎么接?在 2018 年的 2K 窗口下,做到第几步会失忆?
> 3. 下结论:这个任务在 2019 年、2023 年、今天分别能不能做,各自缺什么。
>
> **完成标准**:能指着任务的每一步说出「它依赖哪个催化剂、缺了会怎样」。

## 6. 边界与排错:「热」不等于「万能」

- **误区一:热度 = 能力**。2023 年的 Agent demo 满天飞,但幻觉、不可控、成本高(04 章)是 LLM 带来的新失败模式——催化剂解决「能不能转起来」,不解决「转得可不可信」。
- **误区二:经典 Agent 已死**。在确定性、可验证、要追责的场景(风控规则、流程审批),状态机比自然语言可靠得多;经典 Agent 的规划与意图建模思想也被 LLM Agent 继承(02.03)。
- **误区三:催化剂齐了就自动成功**。还差护栏(呼应 01.07)、评测与人工确认点——「热」是必要条件,不是充分条件。
- **排错自检**:「这个任务 2023 年前为什么没人做成 Agent?」答不出缺哪个催化剂,大概率是需求本身不成立;答得出,再看「那个催化剂今天到货没有、它带来的新风险(幻觉/成本/安全)扛不扛得住」。

## 7. 总结

| 概念 | 一句话 |
|---|---|
| 三代 Agent | 手写规则(经典)→ 单任务训练(RL)→ 通用预训练(LLM),代际差在大脑从哪来 |
| 三个催化剂 | 通用推理 = 能想;function calling = 能做;上下文窗口 = 能记 |
| 到货时间 | 推理 2022.11 触达大众,工具协议 2023.06,大窗口 2023.11 起持续放大 |
| LLM vs 经典 | 智能写在语言里(prompt),不再写在状态机里(代码) |
| 2023 爆发 | 三基座齐 + 大众触达 + 成本骤降,需求/能力/价格三线交汇 |

**思考题**:把「课程助教查资料 → 出题 → 存档」改到 2018 年实现,它会在哪一步、因为缺哪个催化剂而失败?假设明天出现「上下文窗口扩大 100 倍、推理能力不变」的模型——Agent 会立刻全面普及吗?还差什么?

> [!note] 参考答案
> 2018 年主要缺①:没有能可靠拆解「查 → 出题 → 存档」的通用推理,规划只能手写死;即便硬写规则,还缺②(没有可靠的函数调用协议,工具接入脆弱)与③(约 2K 窗口记不住多步)——任务会卡在「无法自主规划」「工具接不上」「第二步忘了第一步」任意一处,这正是经典 Agent 时代没能普及的原因。窗口扩大 100 倍不会立刻全面普及:更大的窗口只解决③,拆解质量仍取决于推理能力①,而工具生态与协议②、成本与延迟、护栏与评测(01.07)依旧是瓶颈——催化剂必须一起到货,这正是本章的结论。
