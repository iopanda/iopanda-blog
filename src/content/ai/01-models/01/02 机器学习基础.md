> 上一章说「模型是从数据里学出来的函数」,本章回答「怎么学」。你会学到机器学习的三种学习范式、训练与评估的纪律(三集划分)、两个最经典的失败模式(过拟合与欠拟合),以及驱动一切学习的引擎:损失函数与梯度下降。这些概念是后续神经网络、Transformer、语言建模章节的共同地基。

**学习目标**:学完本章,你将能够——

1. 用自己的话讲清「机器学习」的定义,并区分监督、无监督、强化三种学习范式;
2. 解释为什么要划分训练集、验证集、测试集,以及为什么绝不能拿测试集调参;
3. 判断一个模型是过拟合还是欠拟合,并说出至少三种缓解手段;
4. 说明损失函数与梯度下降的关系,以及学习率大小带来的后果;
5. 理解「数据决定上限」,并解释为什么大模型的预训练属于自监督学习。

## 1. 概念:机器学习是什么

- **机器学习(Machine Learning,ML)** 是让计算机**从数据中自动归纳规律**,而不是靠人逐条写规则的一类方法。经典定义来自 Tom Mitchell:**「对于任务 T 和性能指标 P,如果程序在经历经验 E 后,在 T 上的 P 得到了提升,就说它在 E 上学到了东西。」** 翻译成人话:做得多了,自然做得更好,并且好到可以量化。
- 用公式对照上一章:`y = f(x; θ)`。传统编程是「人写 f」;机器学习是「**给一堆 (x, y) 样本,让算法自己把 θ 调好**,使得 f 对没见过的 x 也能给出合理的 y」。
- 三个词的关系请记牢:**AI(让机器像人一样智能)→ ML(用数据学出智能)→ 深度学习(用多层神经网络学)**。大语言模型是深度学习的一种,而本章讲的是它们共享的地基。

### 1.1 为什么需要它:规则写不完,标签也标不完

- 上一章说过「例子多、规则难」的任务只能靠学。但机器学习还有第二重动机:**数据里存在人看不见的规律**——比如用户什么时段最容易下单、交易里哪种模式像欺诈,连领域专家都说不清,只能让模型自己去发现。
- 它的作用(工程价值):把「经验」变成可复制、可部署、可持续改进的资产。模型一旦训练好,就能以毫秒级速度服务成千上万的请求;数据更新后重训,能力就跟着涨。
- 详细介绍:**一次完整的机器学习 = 数据 + 模型 + 损失函数 + 优化算法** 四件套。数据提供经验,模型提供假设空间(能学成什么样),损失函数告诉你现在错得有多离谱,优化算法负责把损失压下去。后文 4~6 节逐个展开。

## 2. 三种学习范式:解决三类不同的问题

- 根据「样本里有什么」和「反馈从哪来」,机器学习分为三大范式。**选范式之前先问:我的数据有标签吗?问题是一次性预测还是序列决策?**

| 范式 | 数据 | 核心问题 | 典型任务 |
|---|---|---|---|
| 监督学习 | 带标签(x, y) | 「这是哪个类别/什么数值?」 | 垃圾邮件分类、房价预测、图像识别 |
| 无监督学习 | 无标签(x) | 「数据里藏着什么结构?」 | 客户分群、异常检测、降维可视化 |
| 强化学习 | 无标签,只有奖励信号 | 「一连串动作怎么做收益最大?」 | 游戏 AI、机器人控制、自动驾驶决策 |

### 2.1 监督学习:有标准答案的「例题集」

- **概念**:训练样本自带正确答案(标签),模型学会从输入映射到标签,再对新输入做预测。
- **为什么需要**:大量业务问题本质是「预测」——这封邮件是垃圾吗?这位客户会不会流失?预测的前提是得有历史答案可学,这正是监督学习解决的事。
- **作用**:分类(输出离散类别)与回归(输出连续数值)两大任务覆盖了企业里绝大多数预测场景。
- **详细介绍**:标签质量直接决定上限——标错 5% 的样本,模型就学进 5% 的错误;类别不平衡(欺诈样本只占 0.1%)时,还要用重采样、加权损失等手段处理。经典算法:逻辑回归、决策树、支持向量机,以及(后面会讲的)神经网络。

### 2.2 无监督学习:没有答案,自己找结构

- **概念**:样本没有标签,模型只根据数据本身的相似性发现结构。
- **为什么需要**:标注是昂贵的(需要专家逐条人工标),而互联网上有海量「裸数据」。让模型先自己看数据,往往能省下大量标注成本,甚至发现人没想到的模式。
- **作用**:聚类(把相似样本归组,如客户分群)、异常检测(找出离群点,如信用卡盗刷)、降维(把高维数据压到可视范围,如 PCA)。推荐系统里「买了 A 的人也买了 B」就是关联发现的典型应用。
- **详细介绍**:聚类结果没有「正确标签」可对,只能用轮廓系数等内部指标或业务方人工判断好坏;这也是无监督结果的落地通常需要人参与验证的原因。

### 2.3 强化学习:没有老师,只有奖惩

- **概念**:智能体(agent)在环境(environment)中试错行动,环境返回奖励(reward),智能体学习一套「状态→动作」策略使长期累计奖励最大。
- **为什么需要**:围棋、机器人走路这类**序列决策**问题,既没有正确答案(没有「这一步最优走法」的标签),也无法靠一次性预测解决——每个动作都会影响后面的局面,只能靠试错摸索。
- **作用**:AlphaGo 击败人类棋手、机器人学会抓取、推荐系统动态调价,都是强化学习的舞台。
- **详细介绍**:它学习的是「行动」而非「预测」,样本是 (状态, 动作, 奖励) 序列而非独立数据点;难点在于奖励稀疏(下完一整盘棋才知道输赢)与探索-利用权衡(多试新招还是沿用老招)。你日常接触的大模型对话产品中,人类反馈强化学习(RLHF)也用了它的思想——这属于后训练阶段,详见系列后续章节。

## 3. 训练、验证、测试:三集划分

- **概念**:把数据集按用途切成三份——**训练集**(模型用来学习的「课本」)、**验证集**(调超参数、选模型时用来「模拟考」)、**测试集**(最终「高考」,只考一次)。
- **为什么需要**:模型在见过的数据上成绩好是必然的,真正的问题是「没见过的数据表现如何」。如果调参时也看测试集成绩,模型的超参数就会**悄悄记住测试集**,最后报告的分数虚高——这是最常见的自我欺骗。
- **作用**:验证集让你在开发期反复比较不同方案;测试集只用来做**最终一次**的客观评估,保证你交付的分数能代表真实世界表现。
- **详细介绍**:典型划分比例约 60% / 20% / 20%,数据量少时可用 K 折交叉验证(轮流拿一部分当验证集,平均成绩)。核心纪律一句话:**测试集在模型定稿前绝不参与任何决策**,连「看一眼分布」都算泄漏。时间序列数据还要按时间顺序切分,不能用未来预测过去。

## 4. 过拟合与欠拟合:学过头与没学会

- **概念**:**欠拟合**=模型太简单,训练集上都没学好(如用直线拟合抛物线);**过拟合**=模型太灵活,把训练集的噪声和个例都背下来了,训练成绩很好、验证成绩很差。
- **为什么需要认识它们**:机器学习的大部分调参工作,本质都是在过拟合与欠拟合之间找平衡点。看两条曲线的走势就能定位问题:训练误差和验证误差都高→欠拟合;训练误差低而验证误差高→过拟合。
- **作用**(识别价值):它是训练现场的第一诊断工具——loss 曲线一画,问题方向立刻清晰,不用瞎猜。
- **详细介绍**(缓解手段):

| 手段 | 对付欠拟合 | 对付过拟合 |
|---|---|---|
| 更多数据 | ✅ 特征更丰富 | ✅ 噪声被稀释(最有效) |
| 更复杂/更简单的模型 | ✅ 加大容量 | ✅ 减小容量 |
| 正则化(约束参数别太大) | — | ✅ 如 L1/L2 正则、dropout |
| 早停(验证集不再变好就停) | — | ✅ 防止把噪声也学进去 |
| 数据增强 | ✅ 扩充样本 | ✅ 增加多样性 |

- 生活化类比:欠拟合是复习没到位,考什么都懵;过拟合是只背了练习册原题,题目一换措辞就废。**模型要的不是「背下练习册」,而是「掌握规律」**——后者叫泛化(generalization)。

## 5. 损失函数与梯度下降:学习的引擎

- **概念**:**损失函数(loss function)** 量化「模型输出离正确答案有多远」,是训练时唯一的裁判;**梯度下降(gradient descent)** 是按损失下降最快的方向反复微调参数 θ 的优化算法。
- **为什么需要**:参数空间动辄百万维,不存在手解方程求最优解的可能;而损失函数给每个 θ 一个「海拔」,梯度就是「当前点最陡的下坡方向」,于是学习变成了**下山**:算梯度 → 沿反方向迈一小步 → 再算,直到走到谷底。
- **作用**:损失函数的选择决定了模型在「优化什么」——分类任务用交叉熵(直接优化概率判断),回归任务用均方误差(MSE,惩罚大偏差),选错损失,模型会在错误的评价标准上努力。
- **详细介绍**:更新规则是 `θ ← θ − η·∇L`,其中 **η(学习率)是每步迈多大**。学习率太大:步子跨过谷底,loss 震荡甚至发散;太小:龟速下山,训练半天没进展。实践中常用自适应优化器(Adam 等)自动调节每步大小。梯度下降还有个著名局限:高维空间里可能停在**局部最低点**而非全局最低点,所以初始化、批大小(batch size)等细节都会影响最终质量。神经网络的梯度计算与优化器更新,是下一章[神经网络](/iopanda-blog/ai/01-models/01/03/)的主角。

## 6. 数据决定上限:质量、泄漏与偏见

- **概念**:模型能学到的上限由数据决定,算法只决定「能多接近这个上限」——行业里叫 **garbage in, garbage out(垃圾进,垃圾出)**。
- **为什么需要重视**:数据和代码不同,它的缺陷是隐形的。模型不会报错,只会安静地把数据里的错误、泄漏和偏见学成「规律」,上线后以不可预测的方式爆发。
- **作用**:把「数据工程」当成一等公民,能省下后期数不清的返工——数据清洗、去重、质量抽检、分布监控,都是机器学习工程的核心日常。
- **详细介绍**(三类典型数据病):
  1. **质量差**:错标、重复、过期样本混入,直接污染学习信号;
  2. **数据泄漏**:模型在训练时「偷看」了本不该看到的信息。经典例子:用包含未来信息的字段预测明天(如用「今日是否已还款」预测今日违约)、去重前先切分导致同一用户既在训练集又在测试集——泄漏会让离线指标虚高到离谱,上线即翻车;
  3. **偏见**:历史数据里的歧视与失衡会被放大固化,比如用人历史招聘数据训练的筛选模型学会「偏好男性」。识别并缓解数据偏见,是负责任 AI 的起点。

## 7. 机器学习与大模型:预训练是自监督

- **概念**:今天的 LLM(如 GPT、Llama)属于机器学习,但训练方式很特别:**预训练阶段没有人工标签**——把互联网文本喂给模型,让它预测「下一个 token 是什么」,答案就在文本自身里,猜完立即对答案。
- **为什么需要**:人工标注无法覆盖海量文本,而「预测下一个词」这种**自监督(self-supervised)** 任务能零成本地制造无限训练信号,让模型在千亿 token 上自学语言规律。
- **作用**:正是这种「自己出题自己答」的机制,让模型从「每个任务标一批数据」进化到「一个模型,万千任务」——GPT-2 论文标题直接点破:**语言模型是无监督的多任务学习者**。
- **详细介绍**:自监督属于无监督的进阶形态(用数据自身结构生成伪标签,把无监督问题转成监督问题);预训练之后,再用少量人工标注做监督微调(SFT)与 RLHF 对齐,就得到你日常使用的对话模型。一句话串起全章:**范式是自监督,引擎是梯度下降,纪律是三集划分,命门是数据质量**——这些正是后续章节展开的骨架。

## 8. 总结

### 8.1 本章一览

| 概念 | 一句话 |
|---|---|
| 机器学习 | 从数据中自动归纳规律,使任务表现可量化提升 |
| 三种范式 | 监督(有标签预测)、无监督(无标签找结构)、强化(试错学决策) |
| 三集划分 | 训练集学习、验证集调参、测试集只做最终一次评估 |
| 过拟合/欠拟合 | 背下噪声 vs 没学会;用数据、正则化、早停平衡 |
| 损失+梯度下降 | 损失当裁判、梯度指方向、学习率定步幅 |
| 数据决定上限 | 质量差、泄漏、偏见会让模型学错东西 |
| LLM 预训练 | 自监督:预测下一个 token,无需人工标签 |

### 8.2 思考题

1. 一个垃圾邮件过滤器,应该用监督、无监督还是强化学习?为什么?
2. 同事为了「提高准确率」,反复在测试集上试了 50 个超参数组合,最后选了最好的那个。问题出在哪?
3. 训练 loss 一路下降、验证 loss 却开始回升,此刻模型处于什么状态?你第一步会做什么?
4. 学习率设成 0.001 和 10,分别会发生什么?为什么?
5. 为什么说 LLM 的预训练「不需要人工标注」?它用的伪标签是什么?

> [!note] 参考答案
> 1. 监督学习:垃圾邮件判断有明确答案(是否垃圾),可用历史标注邮件训练分类器;若没有标注,退而求其次可用无监督异常检测发现「可疑」邮件群。
> 2. 测试集被当成了验证集用,超参数已隐式拟合测试集,最终分数严重乐观;正确做法是只留验证集调参,测试集定稿后测一次。
> 3. 过拟合正在发生(模型开始背训练集噪声);先停训练(早停),再考虑加数据、加正则或减小模型容量。
> 4. 0.001 可能太小:每步几乎不动,收敛极慢;10 太大:步子越过谷底,loss 震荡甚至发散。合适的学习率应让 loss 平稳下降。
> 5. 预训练任务是「预测下一个 token」,正确答案就是文本中真实的下一个词,模型自己就能生成标签,故称自监督(伪标签=文本本身)。
