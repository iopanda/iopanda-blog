# Presidio

> 模块定位：从「聚焦敏感信息识别、脱敏与隐私保护」这条路线理解 Safety Guardrails and Moderation。这一目录先不急着写成产品手册，而是先抓住它的设计中心——PII detection、redaction、anonymization。

**本目录计划关注**：
1. Presidio 为什么会出现，它优先解决什么问题；
2. 它的核心抽象、部署形态与集成方式；
3. 它与同组其他产品相比的设计中心差异；
4. 它在课程助教或企业内部 AI 系统中的自然落点；
5. 什么时候适合用它，什么时候不该先用它。

## 建议拆分主题

1. 它主要守哪一层风险
2. 核心抽象与工作流
3. 如何与应用代码或平台集成
4. 与同类产品相比的边界
5. 课程助教高风险场景如何落地

## 适合谁

- 需要先稳住隐私与合规边界的团队
- 学习重点不是 API 清单，而是它默认把什么复杂度提前结构化了。
