# Langflow

> 模块定位：从「面向开发者的可视化 AI agent / RAG 构建框架」这条路线理解 Application Platforms and Workflows。和 Dify、n8n 这类更强调业务平台或自动化平台的产品不同，Langflow 更像把组件图、状态流、调试、部署与 API 暴露做成一个对开发者友好的可视化构建环境。[2][4]

## 这一产品为什么值得单开

- 它不是单纯 low-code 平台，而是更偏开发者友好的 visual framework；
- 它把 multi-agent、RAG、components、custom Python、Flow API 放在一起；
- 它既有 OSS，也有 DataStax 托管版本，形成从本地到托管的上升路径；
- 对产品经理来说，它很适合训练“开发者可视化框架”与“业务交付平台”之间的差异。[2][4]
