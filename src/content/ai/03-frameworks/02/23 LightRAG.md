# LightRAG

> 模块定位：从“轻量图检索”这条路线理解 graph-enhanced RAG。LightRAG 适合回答：如果你想利用图结构改善检索，但又不想一上来背上重平台与重图数据库负担，系统该怎样折中？[44]

**本目录计划关注**：
1. LightRAG 为什么强调 simple and fast；
2. graph-aware retrieval 与传统 vector retrieval 的边界；
3. 轻量图结构在 chunk、entity、relation、query routing 中如何发挥作用；
4. 课程助教 / 知识图谱增强问答案例；
5. 与 LlamaIndex、Haystack、RAGFlow、Pathway 的对比。
