          01.01.03

          神经网络

          2026-09-02 · iopanda

          • course
          • ai-models
          • foundations

          上一章我们学了「模型从数据里学规律」的通用框架;这一章回答:它用什么结构来学? 答案是神经网络——当今几乎所有 AI 模型(从图像识别到大语言模型)的共同骨架。本章围绕四个问题展开:它是什么、为什么非它不可、它有什么用、它内部到底怎么运转。

          学习目标:学完本章,你将能够——

          1. 说清单个神经元的计算过程(加权和 + 激活),并解释为什么必须引入非线性;
          2. 对比 ReLU、GELU、sigmoid 三种激活函数的优劣,并说出 Transformer 系列用哪个;
          3. 复述前向传播、反向传播与优化器更新的完整四步,解释为什么反向传播「快」;
          4. 解释「分层特征」的含义:为什么浅层像词形、深层像语义;
          5. 说明分类任务为何用交叉熵、回归任务为何用均方误差,并列出神经网络的主要局限。

          1. 概念:神经网络是什么

          • 神经网络是一种受大脑神经元启发的计算模型:把大量简单计算单元(神经元)分层连接、层层堆叠,整体构成一个可微的数学函数 y = f(x; θ)。
          • 它的源头可以追溯到 1943 年 McCulloch 与 Pitts 提出的「形式神经元」,1958 年 Rosenblatt 造出感知机(Perceptron),但真正让「多层+可训练」成为现实的,是 1986 年 Rumelhart、Hinton 与 Williams 推广的反向传播算法。
          • 它不是什么:它并不是大脑的仿真——今天的神经网络只是「受启发」的结构,细节(如反向传播)在大脑里并不存在。

          1.1 单个神经元:加权和 + 激活

          一个神经元做两步计算:

          1. 加权和:把每个输入 xᵢ 乘上对应权重 wᵢ,求和并加上偏置 b,得到 z = w₁x₁ + w₂x₂ + … + wₙxₙ + b;
          2. 激活:把 z 送入一个非线性函数 σ,得到输出 a = σ(z)。

          生活化类比:神经元像一个「评审委员会成员」——每个输入(委员意见)按权重(信任程度)打分,加总后经过一道「通过/否决」的闸门才表态。权重 w 和偏置 b 就是训练时要调整的参数;「激活函数」就是这个闸门。

          输入层          隐藏层(神经元们)          输出层
x₁ ──w──┐
x₂ ──w──┼──► z = Σwᵢxᵢ + b ──► a = σ(z) ──► … ──► 预测 ŷ
x₃ ──w──┘

          1.2 为什么必须引入非线性:激活函数的真正意义

          • 概念:如果去掉激活函数,多层网络每一层都只是线性变换 Wx + b,而「线性变换的复合仍然是线性变换」——堆再多层也等价于一层。这样的网络表达能力与单层感知机无异。
          • 为什么需要:现实任务几乎都是非线性可分的。1969 年 Minsky 与 Papert 在《Perceptrons》中指出,单层感知机连最简单的「异或(XOR)」都学不会——这个问题直接导致了第一次 AI 寒冬。
          • 作用:非线性激活让网络能拟合弯曲的决策边界,是「深」真正带来「强」的前提。
          • 详细介绍:理论上能强到什么程度?1989 年 Hornik、Stinchcombe 与 White 证明通用近似定理:只要隐藏单元足够多,单隐藏层的前馈网络就能以任意精度逼近任何连续函数。但注意两点:一是「足够多」可能意味着指数级的神经元;二是定理只保证「存在」,不保证「学得到」。深度网络的价值正在于:多层结构可以用少得多的参数高效表示复杂函数。

          2. 为什么需要它:线性模型与人工特征的天花板

          • 回顾上一章:传统机器学习把「特征工程」留给人类——把图片转成 SIFT 特征、把文本转成词袋,再喂给线性模型。这有三重困境:
            1. 特征要人设计:写特征的人决定了模型上限;
            2. 线性模型太直:多数任务(如图像、语音、语言)的规律是高度非线性的;
            3. 无法端到端优化:特征提取与分类器分开训练,误差无法逐层传导修正。
          • 神经网络一次性解决这三个问题:输入原始数据,中间层自动学特征,输出端直接给预测,整条链路用一个损失函数端到端地训练。
          • 一句话:线性模型 + 人工特征 ≈「人先想好看什么,机器再学怎么判断」;神经网络 ≈「机器连『看什么』也一起学」——后者正是后者能处理图像、语音、自然语言这类高维原始数据的原因。

          3. 它有什么作用:一切现代 AI 的地基

          • 工程价值:今天你接触到的模型几乎全是神经网络——图像识别(ResNet)、语音(Whisper)、机器翻译与对话(GPT、Llama、Gemini)莫不如此。它们共享同一套「神经元堆叠 + 梯度训练」的底座,区别只在层怎么连(卷积、循环、注意力,见 06~08 章)。
          • 对大语言模型的意义:LLM 的「智能」没有额外魔法,就是极大规模的神经网络在文本上训练出来的统计规律;它内部的 Transformer 层(第 06 章)本质仍是「带注意力机制的神经网络层」。
          • 降低使用门槛:因为特征自动学,神经网络把 AI 从「专家调特征」的实验室带进了「给数据就能训」的工程时代——这也是预训练基础模型(01 章)能成立的前提。

          4. 详细介绍:神经网络如何工作

          4.1 激活函数三兄弟对比

          函数 公式 优点 缺点 典型用途
          Sigmoid σ(x) = 1/(1+e⁻ˣ) 输出压缩到 (0,1),可解释为概率 两端饱和区梯度趋近 0(梯度消失);输出非零中心;指数运算慢 二分类输出层、门控机制
          ReLU max(0, x) 计算极快;正区间梯度恒为 1,有效缓解梯度消失;实践效果好 负区间输出恒 0,神经元可能「死掉」;x=0 处不可导 卷积网络默认选择;原版 Transformer(2017)前馈层即用 ReLU
          GELU x·Φ(x) 平滑版 ReLU:按输入值大小「加权」而非按符号「开关」;梯度更平稳,训练更稳 计算稍贵(常用近似式 0.5x(1+tanh[√(2/π)(x+0.044715x³)])) BERT 与 GPT 系列默认激活,现为最强 Transformer 的主流选择
          • 为什么 Transformer 选了 GELU/ReLU 而不用 sigmoid? 深层网络中 sigmoid 的饱和区会让梯度在反向传播时逐层衰减、几乎传不回去(梯度消失);ReLU/GELU 在正区间保持梯度畅通,几十上百层也能有效训练。

          4.2 前向传播:数据流过一次网络

          • 概念:输入 x 从输入层进入,逐层做「加权和 + 激活」,直到输出层产生预测 ŷ,这一过程叫前向传播(Forward Propagation)。
          • 输出层按任务选择:回归任务直接输出数值;二分类输出 sigmoid 压缩到 0~1;多分类接 softmax 得到「各类别概率」。
          • 作用:前向传播既是一次推理(训练好之后用它预测),也是训练的第一步(先算预测,才能算错多少)。

          4.3 反向传播 + 优化器更新:训练的核心四步

          训练一轮的标准循环只有四步:

          1. 前向传播:输入一批样本,算出预测 ŷ 与损失 L(错得越离谱,L 越大);
          2. 反向传播:从输出层往回,用链式法则逐层计算损失对每个参数 w、b 的偏导数 ∂L/∂w(即「每个参数该为错误负多少责」);
          3. 优化器更新:沿负梯度方向迈一小步,如 SGD:w ← w − η·(∂L/∂w),η 是学习率(见 02 章);
          4. 重复:遍历整个训练集多轮(epoch),直到损失收敛。
          • 为什么需要反向传播? 一个直觉:直接求梯度可以,但笨办法代价太高。若用数值微分逐个参数扰动,参数量为 N 就要跑 N 次前向;反向传播借链式法则「一次前向 + 一次反向」就把所有参数的梯度算完——GPU 上训练千亿参数模型(如 LLM)全靠这个效率。反向传播本质是高效地给每个参数分配错误责任,这也是它被称作「信用分配(credit assignment)」的原因。

          4.4 损失函数怎么选:分类交叉熵、回归 MSE

          任务 损失 为什么
          分类(输出概率) 交叉熵(Cross-Entropy) 它衡量「预测分布与真实分布的距离」,与 softmax 概率输出天然配套;梯度大小正比于「预测错多少」,不会因概率接近 0/1 而饱和停滞,训练快
          回归(输出数值) 均方误差(MSE) 连续数值任务关心「误差的大小」,MSE 平方放大离群错误、处处可导、梯度平滑,且在误差服从高斯分布时它正是最大似然估计的等价形式
          • 反例警示:分类任务若用 MSE,softmax 输出接近 0 或 1 时梯度趋近 0,模型「错了却学不动」——损失函数要和输出层的数学性质匹配,不能随手换。

          4.5 表示学习:浅层词形,深层语义

          • 概念:神经网络各层学到的不是随机中间量,而是从具体到抽象的特征层次——每一层在前一层输出的基础上组合出更高级的表示(representation)。
          • 为什么会有层次:反向传播迫使每一层找到「对下一层最有用的压缩表达」,而自然数据(图像、语言)本身就有层级结构,网络便自发学会逐级抽象。
          • 作用:这就是「表示学习(Representation Learning)」——特征是模型自己学出来的,无需人工设计。
          • 详细介绍:以处理文本的网络为例,层次大致是:
          第 1~2 层:词形与局部模式(字母组合、常用词、词缀)
第 3~4 层:词性与句法角色(名词/动词、「主语-谓语」关系)
深层:语义与抽象(同义改写、情感、跨句指代、主题)
          text
          • 对图像同理:浅层检测边缘→中层识别纹理与部件(眼睛、轮子)→深层组合出完整物体。理解这一点,是理解大模型「为什么越深越聪明」、也理解它「为什么浅层错误往往低级的」的钥匙。

          4.6 局限:分布外失败,不可迷信

          • 神经网络学的是训练数据分布内的统计规律,遇到分布外(Out-of-Distribution,OOD)输入——训练时没见过的那类样本——它没有「我不知道」开关,仍会自信地输出一个答案。
          • 具体风险:对训练数据中的偏差(见 02 章)过度敏感;对抗样本(给图片加人眼不可见的噪声)能让它完全认错;生成类模型则会一本正经地编造(幻觉)。
          • 工程启示:不能把神经网络当「真理机器」。上线前必须有分布外评测、输出校验与人工兜底;领域敏感场景优先用检索增强(RAG)补充事实依据。

          5. 总结

          5.1 本章一览

          概念 一句话
          神经元 加权和 + 非线性激活的最小计算单元
          为什么需要非线性 线性叠线性还是线性,学不会 XOR 这类问题
          为什么需要神经网络 自动学特征 + 端到端训练,突破人工特征天花板
          激活函数 sigmoid 饱和易梯度消失;ReLU 快而稳;GELU 是 Transformer 主流
          训练四步 前向算损失 → 反向求梯度 → 优化器更新 → 重复
          反向传播 用链式法则一次算完所有参数梯度,是训练大模型的前提
          损失函数 分类用交叉熵、回归用 MSE,须与输出层匹配
          表示学习 浅层学词形/边缘,深层学语义/物体
          局限 分布外会自信地错,须评测与兜底

          5.2 思考题

          1. 如果把所有激活函数都换成恒等函数(σ(x)=x),100 层的网络等价于几层?为什么?
          2. ReLU 的「神经元死亡」是怎么发生的?GELU 为什么能缓解这个问题?
          3. 为什么说反向传播是「信用分配」?不用反向传播、改用数值微分训练 10 亿参数模型,慢在哪?
          4. 「分类问题能不能用 MSE 当损失?」从梯度角度分析为什么不行。
          5. 神经网络为什么会在没见过的输入上「自信地错」?工程上你能列出哪些缓解手段?

          参考答案

          1. 等价于一层:线性变换复合仍是线性变换,多层堆叠被吸收进单个矩阵乘法,表达能力不随层数增加。
          2. 当某神经元的加权和长期为负,ReLU 输出恒 0,反向传播梯度恒 0,权重再也无法更新,即「死亡」;GELU 负区间仍有非零(虽小)的输出与梯度,信息不会完全断流。
          3. 每个参数的「错误责任」通过链式法则从损失逐层回传,一次反向就能给全部参数分好责任;数值微分要对每个参数单独扰动前向一次,10 亿参数就要 10 亿次前向,成本相差 10 亿倍。
          4. softmax 输出趋近 0/1 时,MSE 的梯度趋近 0,模型错得最狠时反而学得最慢;交叉熵的梯度与「预测偏差」成正比,始终提供有效学习信号。
          5. 它只学会训练分布内的统计规律,输出层天然给出「某种答案」而没有「拒绝」选项;缓解手段:分布外评测、置信度阈值与拒答、检索增强提供事实、人工复核兜底。
