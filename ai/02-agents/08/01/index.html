          应用与案例研究 概览

          2026-09-02 · iopanda

          应用与案例研究 概览

          模块定位：把 02.01~02.07 的能力组装成真实 Agent 应用，并复盘业界成功与失败案例。本模块是结业模块：交付一个端到端「课程助教 Agent」（工具+记忆+护栏+评测+可观测），同时学会从公开事故中提取工程教训。

          学习目标：完成本模块后，你将能够——

          1. 说出代码 Agent、数据分析 Agent、客服/知识 Agent 三种形态的架构差异；
          2. 从公开失败案例中提取可复用的教训（越权、死循环、成本失控）；
          3. 完成端到端 Agent 应用的组装：模型→工具→记忆→护栏→评测→服务；
          4. 输出 Agent 的 model card 与发布评审（复用 01.07 的治理纪律）；
          5. 判断一个 Agent 应用能否上线，并给出监控与回滚方案。

          子主题清单（每章讲义要点）

          01 Agent 应用形态全景

          • 概念：真实 Agent 按风险与自主度分档：辅助型（人确认）/ 任务型（有限自主）/ 自主型（少人干预）
          • 形态对比：代码 Agent（工具=编辑器+执行器）、数据分析 Agent（工具=DB+代码）、知识/客服 Agent（工具=检索+工单）、浏览器 Agent
          • 每形态的典型架构图：模型+哪些工具+哪些护栏
          • 选型框架：任务风险 × 错误代价 → 自主度

          02 代码 Agent 深度案例

          • 概念：让 Agent 读写代码、跑测试、根据报错迭代
          • 架构要点：代码检索、沙箱执行、测试反馈闭环（呼应 02.04 沙箱）
          • 风险：生成代码可执行 = 高风险；权限、超时、依赖隔离
          • 案例：真实代码助手（如 Claude Code/Copilot 形态）的工作原理拆解

          03 数据分析与浏览器 Agent 案例

          • 概念：数据分析 Agent（问自然语言→写查询→出图）与浏览器 Agent（看网页→点按钮→填表）
          • 架构要点：查询生成→执行→校验；浏览器 Agent 的观察（截图/DOM）与动作空间
          • 失败模式：SQL 写错、图表误导、网页结构变化、登录态处理
          • 动手：做一个最小数据分析 Agent：让它回答「课程人数最多的前三章」并生成图表

          04 失败案例复盘

          • 概念：从公开事故学边界：越权工具调用、无限循环烧钱、提示注入夺权、记忆串扰
          • 案例来源：安全厂商报告、OWASP Agentic Top 10、公开事故分析
          • 复盘框架：发生了什么 → 哪层防线失效 → 怎么防（呼应 01.07 风险评审）
          • 教训清单：默认最小权限、默认人确认、默认有预算上限、默认有审计

          05 结业项目：课程助教 Agent 组装

          • 动手：把 02.01~02.07 的成果组装成完整应用： 检索课程资料 + 长期记忆（学员进度）+ 计算工具 + 护栏（注入检测/权限）+ 评测（golden tasks）+ trace
          • 架构图 + 模块清单 + 每模块的验收证据
          • 交付：可运行仓库 + 10 条 golden 任务报告 + 失败案例记录

          06 发布评审与收官

          • 概念：Agent 能否上线 = 证据 + 决策（复用 01.06/07 与 01.07/05 的纪律）
          • Agent 版发布清单：工具权限审计、护栏测试、预算上限、监控指标（完成率/成本/不安全率）、回滚
          • 交付：agent-model-card.md + release-review.md
          • 收官总结：Agent 工程的心法——模型是上限、上下文是杠杆、工具是半径、评测是方向盘、护栏是刹车

          交付物与验收标准

          章 交付物 验收
          03 最小数据分析 Agent 回答一个数据问题并输出可信图表
          05 完整课程助教 Agent 仓库 端到端可运行、各模块有验收证据
          06 model card + 发布评审 能明确回答「能否上线、监控什么、怎么回滚」
